# Plantillas de negocio ficticio

Cuartel general de una tanda de webs de **negocios inventados**, hechas para
enseñar y para reskinear después a clientes reales del mismo sector.

No hay ninguna web aquí dentro. Cada plantilla vive en su propio repo
(`plantilla-<sector>-web`) y se publica en GitHub Pages. Este repo solo guarda
las reglas y la cuenta de lo hecho.

- [`PLIEGO.md`](PLIEGO.md) — cómo se construye cada plantilla: la línea roja de
  lo ficticio, el listón de movimiento, lo obligatorio, las trampas ya pagadas y
  la verificación previa a publicar.
- [`SECTORES.md`](SECTORES.md) — qué sectores están ya cubiertos por la
  biblioteca de clientes reales y cuáles son los huecos, en orden.
- [`REGISTRO.md`](REGISTRO.md) — una fila por plantilla publicada: concepto,
  paleta, tipografía, recurso de movimiento y enlace.

> **Todos los negocios de esta tanda son ficticios.** Nombres, direcciones,
> teléfonos, precios y opiniones son de muestra y no corresponden a ningún
> negocio real.
