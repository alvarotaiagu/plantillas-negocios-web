# Instrucciones del repo

Este repo es el **cuartel general**, no una web. Aquí no se construye ningún
sitio: aquí vive el pliego y el registro.

Antes de tocar nada:

1. Leer [`PLIEGO.md`](PLIEGO.md) **entero**. Manda sobre cualquier costumbre
   general. Se relee antes de cada plantilla nueva, no solo la primera.
2. Leer [`SECTORES.md`](SECTORES.md) para saber qué sector toca y cuáles están
   prohibidos por estar ya cubiertos.
3. Leer [`REGISTRO.md`](REGISTRO.md) para ver qué conceptos, paletas y
   tipografías se han gastado ya en esta tanda.

Cada plantilla se construye **en su propio repo**, no dentro de este. Este solo
recibe una fila nueva en `REGISTRO.md` por plantilla publicada.

## Idioma

Todo en **castellano**: la web, el README de cada plantilla, los commits y el
informe final. El código en inglés solo donde es convención (nombres de API).
